## Core Features (MVP)

1. **Upload Resume** - PDF or DOCX format
2. **Job Description Input** - Paste target job posting
3. **AI Analysis** - Claude analyzes resume vs job requirements
4. **ATS Compatibility Check** - Score formatting, keywords, structure
5. **Optimization Suggestions** - Bullet-by-bullet improvements
6. **One-Click Apply** - Apply all suggestions instantly
7. **Download Optimized Resume** - Multiple formats (PDF, DOCX, TXT)

**Unique Differentiator:** Real-time job description matching (competitors use generic templates)
