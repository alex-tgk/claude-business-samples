## Tips for Best Results

1. **Consistency is key:** Always use the same [LUNA_URL] and [STYLE_URL]
2. **Be patient:** Each image takes ~60 seconds to generate
3. **Use variations:** If you don't like an image, click V1-V4 for variations
4. **Re-roll if needed:** Click 🔄 to completely regenerate
5. **Upscale twice:** After upscaling once, you can upscale again for even higher resolution
6. **Download immediately:** Save all final images right away

---

## Troubleshooting

**"Character doesn't look consistent"**
→ Make sure you're using the exact same [LUNA_URL] in every prompt
→ Double-check you didn't accidentally change the URL

**"Image quality is low"**
→ Always upscale (U1-U4) after initial generation
→ Can upscale multiple times for higher resolution

**"Colors look different between images"**
→ Make sure using same [STYLE_URL] in all prompts
→ Slight variations are normal and okay

**"Wrong aspect ratio"**
→ Pages should be --ar 1:1 (square)
→ Covers should be --ar 4:5 (vertical)
