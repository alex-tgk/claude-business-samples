## DAY 4-5: Layout Book in Canva (4-6 hours)

### Step 1: Set Up Canva Project (30 min)

1. Log into Canva
2. Click "Create a design" > "Custom size"
3. Enter dimensions: **8.5 inches x 8.5 inches**
4. Click "Create new design"
5. Add pages until you have 32 total pages (click "+ Add page" button)

### Step 2: Set Up Bleed (Important!)

1. Click "File" > "Show print bleed"
2. Ensure 0.125" bleed is visible on all sides
3. Your images should extend into the bleed area
4. Keep text INSIDE the safe zone (0.5" from edges)

### Step 3: Import Images (1 hour)

**Pages 1-2 (Front matter):**
- Page 1: Title page
  - Add text: "Luna Learns to Share"
  - Smaller text: "A Heartwarming Story About Friendship and Kindness"
  - Can use a subtle background image or simple color

- Page 2: Copyright page
  - Add text box with copyright info (see BOOK-COMPLETE.md)
  - Simple white or light background

**Pages 3-26 (Story - 24 pages):**
- Upload all your page illustrations (page-01.png through page-24.png)
- Drag page-01.png onto Page 3 in Canva
- Resize to fill entire page INCLUDING bleed area
- Repeat for all 24 story pages

**Pages 27-28 (Back matter):**
- Page 27: "The End" with small Luna illustration
- Page 28: "Also by [Your Name]" or Author bio

### Step 4: Add Text (2-3 hours)

For each story page (3-26), add the text from BOOK-COMPLETE.md:

**Choose Font:**
- Recommended: **Fredoka** or **Quicksand** or **Chewy** (rounded, child-friendly)
- Font size: **20-24pt** for ages 3-6
- Color: Black or dark color with good contrast
- Add text box or subtle drop shadow if needed for readability

**Text Placement:**
- Keep text in safe zone (not too close to edges)
- Consistent placement across pages (e.g., always bottom third)
- Ensure text doesn't cover important illustration elements

**Example for Page 1 (which is Page 3 in Canva):**
1. Click "Text" > "Add a text box"
2. Type: "Luna the bunny had a special toy box filled with the most wonderful toys in the whole wide forest."
3. Choose font: Fredoka, size 22pt, bold, black
4. Position at bottom of page
5. Add semi-transparent white rectangle behind text if needed

Repeat for all 24 story pages.

### Step 5: Design Covers (1-2 hours)

**Front Cover:**
1. Use your cover illustration as background
2. Add text:
   - Title: "Luna Learns to Share" (LARGE, 60-80pt, bold)
   - Subtitle: "A Heartwarming Story About Friendship and Kindness for Kids" (20-24pt)
   - Author: "by [Your Name]" (18-20pt)
3. Make sure text is highly visible (use stroke/outline if needed)
4. Test how it looks as a thumbnail (zoom out)

**Back Cover:**
1. Use back cover illustration as background
2. Add book description text (from BOOK-COMPLETE.md - back cover copy)
3. Leave 2" x 1.25" space in bottom right for barcode
4. Font size 12-14pt for description
5. Ensure good readability

### Step 6: Final Review (30 min)

Check every page:
- [ ] All images extend to bleed
- [ ] Text is in safe zone
- [ ] No typos in text
- [ ] Pages in correct order
- [ ] Cover text is readable
- [ ] Back cover has barcode space
- [ ] Total 32 pages

## DAY 6: Export Files (2 hours)

### Step 1: Export Interior PDF

1. In Canva, click "Share" > "Download"
2. Select **"PDF Print"**
3. Check **"Crop marks and bleed"**
4. Ensure **300 DPI**
5. Download
6. Name file: `luna-learns-to-share-interior.pdf`
7. Open and verify all pages look correct

### Step 2: Create Cover PDF

1. Go to: https://kdp.amazon.com/en_US/cover-calculator
2. Enter:
   - Interior type: **Color**
   - Paper type: **White**
   - Page count: **32**
   - Trim size: **8.5" x 8.5"**
3. Click "Calculate Dimensions"
4. Click "Download Template"

5. In Canva:
   - Create new design with dimensions from calculator
   - Place front cover on right side
   - Place back cover on left side
   - Spine in middle (might be blank for 32 pages)
6. Export as **PDF Print**, 300 DPI
7. Name: `luna-learns-to-share-cover.pdf`

### Step 3: Create eBook Files

**Option A: Kindle Kids' Book Creator (Recommended)**
1. Download free tool from Amazon KDP
2. Open Kindle Kids' Book Creator
3. Import your 24 page images
4. Add text to each page
5. Choose "Fixed Layout"
6. Export .kpf file

**Option B: Simple PDF**
- Export pages 3-26 from Canva as individual JPGs
- Upload to KDP as Kindle book

## DAY 7: Publish to Amazon KDP (3-4 hours)

### Morning: Create Amazon KDP Account

1. Go to https://kdp.amazon.com
2. Sign in with Amazon account (or create new)
3. Complete profile information
4. Add tax information (W-9 for US, W-8 for international)
5. Set up payment method for royalties

### Afternoon: Create Paperback Listing

1. Click "Create" > "Paperback"

**2. Enter Book Details:**
- Language: English
- Title: Luna Learns to Share
- Subtitle: A Heartwarming Story About Friendship and Kindness for Kids
- Author: [Your Name]
- Description: [Copy from BOOK-COMPLETE.md]
- Publishing Rights: I own the copyright
- Keywords: [All 7 from BOOK-COMPLETE.md]
- Categories: [2 from BOOK-COMPLETE.md]
- Age range: 3-6 years
- Grade range: Preschool - Kindergarten

**3. Upload Content:**
- Paperback interior type: **Color**
- Paper type: **White paper**
- Trim size: **8.5" x 8.5"**
- Bleed: **Yes**
- Cover finish: **Glossy**
- ISBN: **Use free Amazon ISBN**
- Upload interior PDF: `luna-learns-to-share-interior.pdf`
- Upload cover PDF: `luna-learns-to-share-cover.pdf`

**4. Preview Book:**
- Click "Preview" when uploads complete
- Check EVERY page carefully
- Verify no errors

**5. Set Pricing:**
- Territories: All territories (worldwide)
- Pricing: **$11.99** USD
- Check other marketplaces (Amazon will auto-calculate)
- Enable Expanded Distribution: **Yes**

**6. Publish:**
- Click "Publish Your Paperback Book"
- Wait 24-72 hours for approval

### Create Kindle eBook

1. From bookshelf, click "+ Kindle eBook" next to your paperback
2. Most details auto-fill from paperback
3. Upload eBook files
4. Upload cover image (front cover only, minimum 2560x1600 px)
5. **Enroll in KDP Select:** Yes (for 70% royalty and Kindle Unlimited)
6. Pricing: **$4.99** (or $0.99 for launch week)
7. Publish
